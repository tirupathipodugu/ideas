# 30 Days, 30 Apps

One new browser app every day for 30 days, built in public by [@tirupathipodugu](https://x.com/tirupathipodugu).

Play them all at **https://tirupathipodugu.github.io/ideas/gallery/**

- Every browser app is plain HTML, CSS and JavaScript in its own folder. There's no build step and no backend.
- Day 7, [Dino Wait](dino-wait/), is a Claude Code mod instead: Chrome's dino game above the prompt while Claude works. Install it at a Claude Code prompt with `/plugin install dino-wait --marketplace tirupathipodugu/ideas`.
- Camera apps run entirely in your browser. No video or photo is uploaded or stored.
- Each day's spec is in `specs/`.
